# Llicència dels continguts

Els textos educatius, els reptes, les il·lustracions (l'Oli, l'òliba espia, i les icones) i els
dissenys de **Missatges secrets** es publiquen amb la llicència
**Creative Commons Reconeixement-CompartirIgual 4.0 Internacional (CC BY-SA 4.0)**:
https://creativecommons.org/licenses/by-sa/4.0/deed.ca

Pots copiar-los, adaptar-los i compartir-los, també a classe, sempre que en citis l'autoria
i comparteixis les obres derivades amb la mateixa llicència.

## Reconeixements

- Les màquines originals del bloc **Calaix +ie** de Joan Jareño (CESIRE-CREAMAT) i la seva xerrada
  «RCZLUL C XYMRCZLUL: El joc dels missatges secrets» han inspirat aquest projecte. No s'hi ha copiat
  cap codi: tot s'ha reescrit i se n'ha comprovat el comportament amb les màquines originals.
- Les màquines originals citaven **Criptografia Numaboa** i **Ars Cryptographica** (Didier Müller).
- El codi font és lliure amb llicència MIT (vegeu `LICENSE`).
